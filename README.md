# Мудрые мысли

Android-приложение: каждый день — новая мысль великих людей.

## Что умеет

- **Мысль дня.** Каждый день новая; повторов нет, пока не будут показаны все.
  Листать на вчера и завтра — стрелками или свайпом, «Ещё мысль» — случайная.
  Под датой — сколько дней подряд вы заходите (🔥).
- **Лента.** Мысли во весь экран на цветных фонах, листаются вверх (как в
  Motivation). Двойное касание — в избранное. Сверху — выбор темы.
- **Обзор.** Поиск, 16 тем (счастье, любовь, дружба, мудрость, время, труд,
  богатство, «с улыбкой» и др.) и авторы со счётчиками. Темы определяются по
  ключевым словам на русском и английском, поэтому работают и для своих цитат.
- **Язык мыслей:** русские, английские или все (при первом запуске и в настройках).
- **Озвучка** 🔊 — синтезатором речи телефона, русским или английским голосом.
- **Дневник** ✎ — записать, что мысль значит для вас; к каждой мысли свой
  вопрос для размышления. Все записи — на вкладке «Моё» → «Дневник».
- **Поделиться** текстом, картинкой-открыткой (8 оформлений) или скопировать.
- **Виджет на рабочий стол** с мыслью дня.
- **До трёх напоминаний в день:** первое — мысль дня, остальные — ещё по одной.
- **Источники.** Свои источники и цитаты (по одной или списком), включение и
  выключение источников, ссылки на книги и сайты для чтения.
- **Резервная копия** всего приложения (с дневником) в один .zip.

## Откуда цитаты

Встроенная подборка (около 4100 мыслей: 1800 на русском и 2300 на английском)
собирается скриптом `ci/fetch_quotes.py` с [русской](https://ru.wikisource.org/)
и [английской](https://en.wikisource.org/) Викитеки — это книги в общественном
достоянии:

| Источник | Что это |
|---|---|
| Л. Н. Толстой, «Круг чтения» | мысли многих писателей на каждый день (на Викитеке — часть дней) |
| Ларошфуко, Вовенарг, Лабрюйер, Монтескьё — «Избранные мысли» | изд. «Посредник», 1908, под редакцией Толстого |
| Джон Рёскин, «Избранные мысли» | «Посредник», 1908 |
| Эпиктет, «Афоризмы» | пер. В. Г. Алексеева, 1891 |
| Марк Аврелий, «Наедине с собой» | пер. С. М. Роговина, 1914 |
| Козьма Прутков, «Плоды раздумья» | 1854—1860 |
| Marcus Aurelius, *Meditations* | tr. George Long |
| La Rochefoucauld, *Moral Reflections, Sentences and Maxims* | 1851 |
| Benjamin Franklin, *Poor Richard's Almanack* | 1733—1758 |
| Mark Twain, *Pudd'nhead Wilson's Calendar* | 1894, 1897 |
| Oscar Wilde, *Phrases and Philosophies for the Use of the Young* | 1894 |
| Kahlil Gibran, *Sand and Foam* | 1926 |
| *The Sayings of Confucius* | tr. Lionel Giles, 1907 |
| *The Dhammapada* | tr. F. Max Müller, 1881 |

Слишком длинные отрывки (рассказы, рассуждения на страницу) в подборку не
попадают — только мысли до 400–500 знаков.

Ссылки для чтения: «Мысли мудрых людей на каждый день» Толстого (Яндекс Книги),
«Круг чтения» и «На каждый день» в PDF с tolstoy.ru, Викицитатник, Викитека,
Lib.ru, Project Gutenberg.

## Сборка

Всё собирается на GitHub, ничего ставить не нужно.

- Каждый push в `main` запускает **«Собрать APK»**. Свежий APK всегда лежит по ссылке
  `https://github.com/Murmuridis/mysli/releases/latest/download/mudrye-mysli.apk`.
  APK подписан постоянным ключом из `ci/`, поэтому новая версия ставится поверх
  старой, и избранное с добавленными цитатами сохраняется.
- **«Обновить цитаты»** (вкладка Actions → Run workflow) заново скачивает книги
  с Викитеки и сохраняет `assets/data/quotes.json`. Чтобы добавить книгу в
  подборку, допишите её в список `SOURCES` в `ci/fetch_quotes.py`.
  Если в новой подборке есть новые цитаты, увеличьте `_seedVersion` в
  `lib/store.dart` — тогда они добавятся и в уже установленное приложение.
