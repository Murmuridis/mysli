# Мудрые мысли

Android-приложение: каждый день — новая мысль великих людей.

## Что умеет

- **Мысль дня.** Каждый день новая. Порядок перемешан, но постоянен:
  повторов нет, пока не будут показаны все. Стрелками или свайпом можно
  листать вчера и завтра, кнопка «Ещё мысль» показывает случайную.
- **Напоминание** с сегодняшней мыслью в выбранное время
  (Настройки → «Присылать мысль дня»). Работает и после перезагрузки телефона.
- **Поделиться** текстом или **картинкой**: квадратная открытка с цитатой
  в одном из четырёх оформлений (Ночь, Бумага, Олива, Закат).
  Есть также «Скопировать» и **избранное**.
- **Поиск** по тексту и автору.
- **Источники.** Каждый источник можно выключить (тогда его мысли не
  попадают в мысль дня), открыть его ссылку, добавить в него цитату вручную
  или **списком** — вставить текст из книги или сайта:

  ```
  Истина — солнце разума.
  — Вовенарг

  Если хочешь быть счастливым, будь им. || Козьма Прутков
  ```

  Кнопка «Источник» добавляет свой источник (книга, сайт, подборка).
  Ниже на вкладке — «Книги и сайты для чтения»: ссылки без встроенных цитат.
- **Резервная копия** всего приложения в один .zip и восстановление из неё.
- Светлая и тёмная тема, размер текста настраивается.

## Откуда цитаты

Встроенная подборка собирается скриптом `ci/fetch_quotes.py` с
[Викитеки](https://ru.wikisource.org/) — это книги в общественном достоянии:

| Источник | Что это |
|---|---|
| Л. Н. Толстой, «Круг чтения» | мысли многих писателей на каждый день (на Викитеке — часть дней) |
| Ларошфуко, Вовенарг, Лабрюйер, Монтескьё — «Избранные мысли» | изд. «Посредник», 1908, под редакцией Толстого |
| Джон Рёскин, «Избранные мысли» | «Посредник», 1908 |
| Эпиктет, «Афоризмы» | пер. В. Г. Алексеева, 1891 |
| Марк Аврелий, «Наедине с собой» | пер. С. М. Роговина, 1914 |
| Козьма Прутков, «Плоды раздумья» | 1854—1860 |

Слишком длинные отрывки (рассказы, рассуждения на страницу) в подборку не
попадают — только мысли до 400–500 знаков.

Ссылки для чтения: «Мысли мудрых людей на каждый день» Толстого (Яндекс Книги),
«Круг чтения» и «На каждый день» в PDF с tolstoy.ru, Викицитатник, Викитека,
Lib.ru, Project Gutenberg.

## Сборка

Всё собирается на GitHub, ничего ставить не нужно.

- Каждый push в `main` запускает **«Собрать APK»**. Свежий APK всегда лежит по ссылке
  `https://github.com/Murmuridis/mysli/releases/latest/download/mudrye-mysli.apk`.
  APK подписан постоянным ключом из `ci/`, поэтому новая версия ставится поверх
  старой, и избранное с добавленными цитатами сохраняется.
- **«Обновить цитаты»** (вкладка Actions → Run workflow) заново скачивает книги
  с Викитеки и сохраняет `assets/data/quotes.json`. Чтобы добавить книгу в
  подборку, допишите её в список `SOURCES` в `ci/fetch_quotes.py`.
  Если в новой подборке есть новые цитаты, увеличьте `_seedVersion` в
  `lib/store.dart` — тогда они добавятся и в уже установленное приложение.
